# Local preprocessing models

The model registry pins the exact source URL, version, and SHA-256 for every bundled model.
The three model assets are distributed for MediaPipe Tasks under the Apache License 2.0.
They run only on the Android device and provide transfer-selection signals. Face outputs are
anonymous, session-local similarity signals and are not used for identity recognition.

Runtime documentation:

- https://developers.google.com/edge/mediapipe/solutions/vision/face_detector
- https://developers.google.com/edge/mediapipe/solutions/vision/image_embedder
- https://developers.google.com/edge/mediapipe/solutions/vision/object_detector
